    What this demo implements
    
      
      
        
    • Hashed passwords: PBKDF2-SHA256, 310,000 iterations, unique 16-byte salt, constant-time comparison. (bcrypt/Argon2 need a server; see the Flask version.)
      • 
        
    • Validation: username whitelist, email format, length + strength rules, common-password check.
      • 
        
    • Sessions: random 256-bit token, 15-minute idle timeout, 8-hour maximum, cleared on logout.
      • 
        
    • Brute-force defence: account locks for 60 seconds after 5 failed attempts; generic error messages; dummy hash for unknown users to hide timing.
      • 
        
    • 2FA: standard TOTP (RFC 6238), compatible with any authenticator app, ±30 s drift, replay protection.
      • 
        
    • XSS: all user-provided text is inserted with textContent, never as HTML.
      • 
      
    
    
    
  
    

  
    Educational demo. Client-side code can't protect a real database: enforce these rules on the server as well.
