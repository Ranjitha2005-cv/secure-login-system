# Secure Login System

## About the Project
A beginner-friendly project to demonstrate secure user authentication and password protection.

## Features
- User registration and login
- Password hashing
- Input validation
- Protection against SQL injection (when implemented with parameterized queries)
- Secure session management (when implemented)

## Technologies
- Python
- SQL
- HTML and CSS

## Purpose
This project aims to understand the basics of web application security and secure authentication.

## Status
Project setup in progress. Features will be documented as they are implemented.
